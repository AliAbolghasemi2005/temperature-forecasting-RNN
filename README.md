# Temperature Forecasting with RNN

A deep learning RNN project using the Jena Climate dataset.

## Dataset

The dataset contains weather observations recorded in Jena, Germany, from 2009 to 2016.

[Download Jena Climate Dataset](https://s3.amazonaws.com/keras-datasets/jena_climate_2009_2016.csv.zip)

Extract the CSV file into the project directory before running the code.

## Requirements

- Python 3
- NumPy
- Matplotlib
- TensorFlow / Keras

Install the required libraries:

```bash
pip install numpy matplotlib tensorflow
```

## Usage

1. Clone this repository.
2. Install the required libraries.
3. Download and extract the dataset.
4. Run the training script:

   ```bash
   python train.py
   ```

## Note

The dataset is excluded from this repository using `.gitignore`. Verify the original dataset's licensing terms before redistributing it.
